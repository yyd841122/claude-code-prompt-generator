## 2. Short Product Description

Claude Code Prompt Generator is a lightweight static frontend tool that helps developers create structured Markdown prompts for Claude Code, opencode, and AI coding agents. Instead of writing messy prompts from scratch, you fill in a simple form with your task title, agent role, project background, goal, and constraints. The tool generates a complete structured prompt with Git and test requirements built in. It includes three built-in examples to get started instantly, supports one-click copy and Markdown file export, and works entirely in your browser with no backend, no login, and no AI API key required.

**Long Description:**
Claude Code Prompt Generator is a browser-based tool that helps developers create structured Markdown prompts for Claude Code, opencode, and other AI coding agents. Instead of writing prompts from scratch, users fill in a simple form with task title, agent role, project background, goal, steps, output format, and constraints. The tool generates a complete, structured prompt with customizable Git commit and test report sections.

The tool includes three built-in examples (login page creation, UI bug fix, Tester Agent review) that auto-fill the form for instant start. Generated prompts can be copied to clipboard or exported as .md files with a single click. The entire application is a static frontend — no backend, no login, no database, no AI API required. All user input is processed locally in the browser and never uploaded. The interface supports both English and Chinese, and the layout is fully responsive for desktop and mobile use.
