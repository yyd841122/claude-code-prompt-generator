# Claude Code Prompt Generator v0.1.0 Summary

## 1. Project Overview

Claude Code Prompt Generator is a lightweight static web tool for creating structured Markdown prompts for Claude Code, opencode, and AI coding agents.

这是一个纯前端静态工具站，用于生成适合 Claude Code、opencode 和 AI 编程 Agent 使用的结构化 Markdown 提示词。

## 5. Completed Features

- Structured prompt generation
- Safe default content
- Prompt Examples
- Example card click-to-fill
- Copy Prompt
- Download .md
- Download empty-state hint
- Start Generating button
- Footer links
- Feedback link
- Privacy Note
- Responsive mobile layout
- Cloudflare Pages deployment

## 6. Deployment

- Repository is hosted on GitHub
- Site is deployed through Cloudflare Pages
- Push to main triggers automatic deployment

## 7. Privacy Boundary

- Static frontend only
- Inputs are processed in the browser
- No login
- No database
- No payment
- No AI API
- No backend upload in current version

## 8. Manual Test Checklist

- Page opens on mobile

- Privacy Note displays correctly

## 9. Current Limitations

- No AI API integration
- No user accounts
- No saved history
- No analytics
- No custom domain yet
- No dedicated Privacy Policy page
- No multi-language toggle
- No template management system
