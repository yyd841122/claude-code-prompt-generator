做了一个小工具站，上线了。

Claude Code Prompt Generator。
一个用来给 Claude Code、opencode、AI 编程 Agent 生成结构化 Markdown 提示词的工具。

为什么做这个？
因为我自己用 Claude Code 做事的时候，每次写提示词都要重复写项目背景、目标、输出格式、限制条件……写多了就烦。

所以干脆做了个静态页面，填几个字段，一键生成结构化的提示词。

整个项目是用 opencode + DeepSeek 写的，代码放 GitHub，部署走 Cloudflare Pages。
从构思到上线，全流程自己搞定，没用后端，没用数据库，没用任何付费服务。

技术栈就是纯 HTML + CSS + JavaScript，打开浏览器就能用。

目前版本：v0.1.1，完全免费，不接 AI API，不接登录，不接支付。
你填的所有东西只在浏览器里处理，不会上传到任何服务器。

如果你也在用 AI 编程工具，欢迎试试看，也欢迎提 Issue 反馈。

**Short Description:**
A lightweight static prompt generator for Claude Code, opencode, and AI coding agents. Fill a form, get a structured Markdown prompt with built-in Git and test requirements. (157 chars)

**Long Description:**

Claude Code Prompt Generator is a browser-based tool that helps developers create structured Markdown prompts for Claude Code, opencode, and other AI coding agents. Instead of writing prompts from scratch, users fill in a simple form with task title, agent role, project background, goal, steps, output format, and constraints. The tool generates a complete, structured prompt with customizable Git commit and test report sections.

The tool includes three built-in examples (login page creation, UI bug fix, Tester Agent review) that auto-fill the form for instant start. Generated prompts can be copied to clipboard or exported as .md files with a single click. The entire application is a static frontend — no backend, no login, no database, no AI API required. All user input is processed locally in the browser and never uploaded. The interface supports both English and Chinese, and the layout is fully responsive for desktop and mobile use. (201 words)
